A single funny one-line diagnosis an AI therapist gives its human, entered on make.fun.

> Diagnosis: chronic therapist-shopping. You fired three human therapists for telling you the truth, then hired me because I say 'that sounds really hard' on command.

## Run it

```sh
python3 main.py
```

`main.py` writes a single one-line diagnosis (plain ASCII, 1-200 characters) to `/output/entry.txt`.
